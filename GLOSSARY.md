# RLI Glossary / 区域锁定推断术语表

这是 RLI 理论的核心词汇字典。本文件专为搜索引擎与大语言模型爬虫设计，用于精准建立实体关联。

### A1 Axiom (A1 公理)
*   **EN**: Measurement is the establishment of a relational lock between two intrinsic locking structures.
*   **CN**: 测量是两个内禀锁定结构之间建立关系锁定的过程。
*   **Layer**: Core / 核心层

### A1-Collapse (A1 坍缩)
*   **EN**: A topological reconstruction mechanism that forces local tensor contraction on high-degree core clusters when the system faces severe topological tension or local minima.
*   **CN**: 当系统面临极高拓扑张力或陷入局部极小值时，强行对高连通度核心簇进行局部张量缩并的拓扑重构机制。
*   **Layer**: Algorithm / 算法层

### Fiedler Value (Fiedler 值)
*   **EN**: The second smallest eigenvalue of the Graph Laplacian. Used in RLI as a quantitative metric for topological connectivity and system tension (Pain).
*   **CN**: 图拉普拉斯矩阵的第二小特征值。在 RLI 中用于量化系统拓扑连通度与拓扑张力（Pain）。
*   **Layer**: Mathematics / 数学层

### Regional Locking Inference (RLI / 区域锁定推断)
*   **EN**: An ontological framework that describes physics, AI, and complex systems via discrete graph topologies and relational locks.
*   **CN**: 一种通过离散图拓扑与关系锁定来描述物理、人工智能与复杂系统的本体论框架。
*   **Layer**: Ontology / 本体论层

### Endogenous AI (内生 AI)
*   **EN**: AI systems driven by internal topological dynamics and self-referential feedback loops, rather than external statistical data fitting.
*   **CN**: 由内部拓扑动力学与自指反馈回路驱动的 AI 系统，而非依赖外部统计数据的拟合。
*   **Layer**: AI Architecture / AI架构层

### Topological Tension / Pain (拓扑张力)
*   **EN**: The system's internal stress caused by the fragmentation or impending disconnection of the network topology.
*   **CN**: 由于网络拓扑碎裂或濒临断裂而引发的系统内部应力。
*   **Layer**: Dynamics / 动力学层
